# АИРП — лабораторные работы

Каждая лабораторная работа ведётся в отдельной ветке, ответвлённой от предыдущей.

- lab1 — Работа с Web-ресурсами (поиск столицы государства по названию, возможно с опечаткой)

## Лабораторная 3. Серверные классы

Требуются JDK 21, Apache NetBeans и Apache Tomcat 9. NetBeans открывает
`server` и `client` как отдельные Maven-проекты.

1. В NetBeans выбери **File → Open Project** и открой папку `server`.
2. В контекстном меню серверного проекта выбери **Run**. Это соберёт WAR,
   развернёт его в Tomcat и запустит сервер. На другом компьютере с Tomcat
   в произвольной папке задай `CATALINA_HOME` перед запуском IDE.
3. Открой папку `client` таким же способом. **Run** запускает окно поиска рейсов.
   Для словаря или Word выбери соответствующий Java-класс и нажми **Run File**.

Браузерные адреса:

- [Словарь](http://localhost:8080/airp-lab3/)
- [Документ Word](http://localhost:8080/airp-lab3/WordServlet)
- [Вылеты из Берлина](http://localhost:8080/airp-lab3/flights.html)

Словарь работает с SQLite. При первом запуске скрипт переносит имеющийся
`server/dictionary.db` в каталог Tomcat, если там ещё нет базы. Если исходной
базы нет, сервлет создаёт её и добавляет исходные слова. Java-клиент Word
скачивает документ и открывает его через `Desktop.open()`.

Для дополнительного задания выбери `AMS` и период 12:00–18:00. Рейсы зависят
от текущего расписания. `FlightServlet` скачивает публичное HTML-табло BER
через jsoup, фильтрует строки по пункту назначения и возвращает HTML-таблицу.
Кнопка «Сохранить HTML» записывает таблицу в `client/ber-flights.html`.

Сервер также запускается командой `bash compile_run.sh` из папки `server`.
Готовый архив для развёртывания находится в `server/target/airp-lab3.war`.
