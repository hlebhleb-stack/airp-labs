## Лабораторная 3. Дополнительное задание — вылеты из Берлина (BER)

Проверено с JDK 21 (проверка версии — `javac -version`). При первом запуске серверный
скрипт скачивает JAR jsoup в `server/lib` с помощью `curl`.

Из корня ветки лабораторной в первом терминале:

```sh
cd server
bash compile_run.sh
```

В отдельном терминале из корня проекта откройте окно Java-клиента:

```sh
cd client
bash compile_run.sh flights
```

Нажмите «Показать рейсы». По умолчанию выбран Амстердам (`AMS`) за период
12:00–18:00. Можно указать другой город латиницей или код IATA. Пустое поле
показывает все рейсы за выбранный период. Кнопка «Сохранить HTML» записывает
результат в `client/ber-flights.html`.

Для запуска уже собранного окна из папки `client` используйте
`java -cp out lab3.client.FlightClient`. Команда
`java -cp out lab3.client.FlightClient AMS 12` сохраняет HTML из терминала.
Браузерная форма доступна по адресу [flights.html](http://localhost:8080/flights.html).

Форма и Java-клиент вызывают `GET /FlightServlet`. В `processRequest` сервер
загружает [открытое независимое HTML-табло](https://www.berlin-airport.com/departures) через
jsoup, находит строки по селектору `.flights-info .flight-row:not(.flight-titol)`
и фильтрует их по столбцу назначения. Сервлет заполняет таблицу с номером рейса,
временем вылета, авиакомпанией, терминалом и статусом с помощью `PrintWriter`
и возвращает `text/html; charset=UTF-8`. Табло показывает отдельные вылеты из
BER. Поиск маршрутов с пересадками здесь не выполняется.
